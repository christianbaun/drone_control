# drone_control v0.1.0 — Initial release

## English

First public version of a local Python CLI for ArduCopter telemetry and supervised MAVLink flight sequences. Developed with assistance from OpenAI Codex CLI. Licensed under Apache-2.0.

### Features

- Terminal dashboard for battery, attitude, altitude, GPS, magnetometer, RC RSSI, VTX settings, and EKF notices.
- ExpressLRS TX Backpack discovery over WiFi and direct serial MAVLink connections.
- Arming-only ground tests with flight-controller rejection messages.
- TOML configuration for a vertical arm → takeoff → hold → land sequence.
- Command cancellation after detected RC/FC mode changes; no force-arming.
- Read-only UBX GPS diagnostics over prepared USB passthrough.
- English/German README, example mission, and battery display profile.

### Installation

Python 3.11 or newer is required. Extract the source archive and run from its directory:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m drone_control run --mission examples/hover.toml
```

This command only previews the sequence and opens no aircraft connection. See README.md before connecting or executing commands.

### Validation and limitations

- 70 unit tests passed during release preparation.
- Connection, telemetry, and arming have been tried on real hardware, including MicoAir743 V2 with ArduCopter 4.6.2 and ExpressLRS.
- Autonomous flight reliability has not been established by these checks. Test in SITL first and perform ground checks with propellers removed.
- Mission altitude is relative to Home, not a direct LiDAR ground-distance target.
- No waypoint navigation, obstacle avoidance, or GUI. CLI messages currently use German.
- Battery colors depend on the FC remaining-capacity estimate, not voltage thresholds.
- Wheel installation provides the Python package; example missions, profiles, and guides are supplied in the source archive.

## Deutsch

Erste öffentliche Version der lokalen Python-Kommandozeilensteuerung für ArduCopter mit MAVLink-Telemetrie, Arming-Diagnose und einem konfigurierbaren Start–Halten–Land-Ablauf.

Die Entwicklung erfolgte unter Mithilfe von OpenAI Codex CLI. Lizenz: Apache-2.0. Python ab 3.11 ist erforderlich. Installation und Beispiele stehen in der zweisprachigen README.

Bei der Release-Vorbereitung bestanden alle 70 Unit-Tests. Verbindung, Telemetrie und Armen wurden an realer Hardware erprobt; dies bestätigt keinen sicheren autonomen Flug. Vor dem Flugbetrieb SITL-Tests und Bodentests ohne Propeller durchführen und FC-Failsafes konfigurieren. Missionshöhen beziehen sich auf Home. CLI und Dashboard verwenden derzeit deutsche Texte.
